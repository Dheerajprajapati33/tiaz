# TIA'Z Digital Gold Admin Panel

Enterprise admin dashboard for TIA'Z digital gold platform featuring KYC verification, gold orders, live rates, holdings, transactions, and user management.

## Tech Stack
- React 19 + Vite
- TailwindCSS v4
- Zustand
- Lucide React & Motion

## Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server on port 3001
npm run dev
```

The application will be accessible at `http://localhost:3001`.
